# ScopeForm: agent code and benchmark

Implementation of **ScopeForm: Context-Faithful Formalization for Medical Agents over Evolving Multi-Document Evidence**.

- [Benchmark and data](benchmark/README.md): 120 source clusters, 519 claims, four updates, and five settings.
- [Agent and method code](code/README.md): LLM Agent baseline, contextual formalization, semantic library, SMT reasoning, and ID-addressed repair.
- [Semantic library](docs/semantic_library/README.md) and [design foundations](docs/semantic_library/DESIGN.md).
- [中文使用说明](README_中文.md).

This release contains code, benchmark inputs and scoring targets, configurations, and constructed demonstration inputs. Recorded experimental results, predictions, model responses, execution traces, and result tables are not included.

## Install and demonstrate

```bash
python3.10 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/demo.py
python scripts/demo.py --backbone qwen
```

The constructed example runs the compiler, solver, and ID-addressed edit locally without model calls. Generated outputs are written to ignored local directories.

## Run and evaluate

```bash
# Prepare a ten-source pilot without model calls.
python scripts/run_experiment.py --backbone deepseek --scope pilot --out runs/ds --prepare-only

# Execute the pilot, including fresh initial phases.
python scripts/run_experiment.py --backbone deepseek --scope pilot --out runs/ds

# Score your generated run with the benchmark evaluator.
python scripts/reproduce.py --run-dir runs/ds --out runs/ds/evaluation
```

The runner reads `DEEPSEEK_API_KEY` from the environment or a hidden prompt. For local Qwen, use `--backbone qwen --endpoint http://127.0.0.1:18227/v1`; `scripts/serve_qwen.sh` launches a server from existing model weights. `--scope full` selects all 120 sources. `--settings fresh labels index guard index_guard` selects the five settings.

Initial phases are generated by default. Each source's initial checkpoint is shared across the baseline and ScopeForm arms. Native reading, formalization, diagnosis, and repair feedback share a total cap of 40 model requests and 40 actions per phase. Guard is an evidence-access setting applied to both arms.

To use your own previously saved initial checkpoints, supply `--initials recorded --initials-archive /path/to/shared_initials.tar.gz`. Recorded-case replay also requires external inputs; see `python scripts/replay_case.py --help`.

The DeepSeek and Qwen inference snapshots, benchmark runtime, and evaluator are preserved. Historical `private` and `LOCAL_ONLY` filenames separate scoring targets from agent-visible evidence; inference does not load evaluator targets. Model weights and credentials are not included.
